Always give UI-based navigation instructions when directing Brian to test something in the ComplyHub platform. Brian navigates via the app UI, not by typing raw URLs into the browser.

**Why:** Brian asked for this explicitly after being told to "navigate to /dashboard/registers/pdr" with no UI context about how to get there from his current screen.

**How to apply:** Instead of "navigate to `/dashboard/registers/pdr`", say "click PDR in the left nav under Registers" or "go to Registers → Professional Development in the sidebar". Always describe the click path from where Brian currently is. Only include the URL as a fallback if the UI path is unclear.
