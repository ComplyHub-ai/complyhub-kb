The 3 improvement recommendations — in plain English
1. When a question is ambiguous, look up both sources instead of guessing.
Right now ComplyBot makes a single either/or choice: either it pulls up the legislation rulebook, or it pulls up the how-to navigation guides — never both. If it guesses wrong, it answers with the wrong reference material behind it. The improvement: when a question could go either way, just look up both and let ComplyBot use whichever is actually relevant. This removes almost all the damage a wrong guess can do, at the cost of one extra lookup. This is the highest-value, lowest-risk change — better than perfecting the guessing logic.

2. Actually learn from the thumbs up/down feedback (the real "learning loop").
Today ComplyBot writes down every question and answer but never re-reads any of it, so it never improves. Once the thumbs feature is live, the improvement is: when someone thumbs-down an answer, a human periodically reviews those, and two things feed back in — (a) a small growing list of "this phrasing should have been handled as X" that sharpens the mode-picking, and (b) whenever ComplyBot couldn't find a matching rule in its legislation library, that question goes on a "gaps to fill" list so the library grows exactly where it's weakest. It's semi-automatic with a human checking — not the AI retraining itself unsupervised. This is the genuine "learning mechanism" that was discussed but never actually built.

3. Let the AI itself judge the question's intent (lower priority).
Instead of matching phrases with fixed rules, you could have a quick, cheap AI call read the question and decide "compliance or navigation?" It handles unusual wording better than fixed rules. But it costs a little money and time on every question and adds another thing that can go wrong — and improvement #1 already covers most of what it would buy you. So I'd keep this in the back pocket and only reach for it if #1 and #2 aren't enough.
